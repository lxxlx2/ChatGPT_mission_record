Personal-use monitoring utility

300-3000

A self-operated research and notification tool for crypto market and public-chain activity, including the Frank wallet signal monitor.

About this application

300-3000 analyzes selected public blockchain activity and uses predefined, read-only decision rules to display research observations and optional alerts. The software runs in an instance managed by the account owner. It does not place trades, sign wallet transactions, or offer a public trading service.

  • Read-only monitoring of selected public on-chain events and wallet activity.
  • Local dashboards and optional desktop notifications.
  • Optional Gmail notifications for eligible, time-sensitive decisions.
  • Gmail Sent-message checks to reconcile deliveries and avoid duplicate alerts.

How Google account access is used

Google OAuth access is used by the account owner's local installation to send selected notifications using Gmail and to confirm deliveries by searching and reading matching messages in the account's Sent folder. This website does not request credentials or run an OAuth login flow.

Privacy and contact

Read the Privacy Policy for details about Google user data, local storage, retention and access revocation. This informational site has no sign-in form, analytics script, or user-data collection form.

For application questions, use the project issue tracker. The Google OAuth consent screen also lists the application support email.
