## 第一优先级是准确性

采集完整性按明确的钱包、链、finalized 槽位区间、原件摘要和来源记录。逐笔核对签名是否持久化、槽位是否匹配、分类是否有足够证据，以及应触发的信号是否存在。另列收件未知和送达证据。独立参考不足或区间不完整时保留缺口，禁止把未覆盖算成零漏报。Scanner 轮询间隔与源头追平状态只用于观察运行。

首先实现可重复的离线对账。用明确的参考快照对照账本中的检测、入库和分类，区分可证实的缺失、冲突和未知。后续补采应从已保存游标和待原件状态继续，验证中断、重复、原件缺失以及断线后的恢复。明确来源口径后，再记录真实链事件到入库、信号到送达、CA 首份可读结果和完整报告的耗时。完整查询以固定输入核对候选集和缺口，提速前后保留同一数据范围。
