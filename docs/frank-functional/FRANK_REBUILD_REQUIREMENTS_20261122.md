## 1. 当前决定

- **监控首先回答「Frank 实际买了哪些 Solana Meme」。** 以有证据的主动买入为准。默认页面和新增通知只接收合格买入。持仓、卖出、被动转入、账户操作、失败、跨链付款与未知交易可用于独立账本和排错，不能挤进买入页面或触发买入邮件。
- **查询首先回答「币是什么，为什么有人关注，行情怎么走，谁在交易，筹码和权限有什么风险」。** 按 GMGN 的查询功能和阅读顺序逐项对齐，使用 Frank 的界面标识；Fomo 提供叙事和持仓表达的参照。交易、挂单、跟单和账户操作不属于这项查询。
- **产品入口重新做，原成果可回查。** 保留旧 Git 分支、已部署版本、台账、原件、检查点、来源信号和历史通知。在本分支重定页面和准入规则。已有数据、解析、安全与恢复机制先验再复用。首次交付仅此两份文档。
- **准确、及时、免费。** 优先解决漏报、错报和查询延迟。重做不得用更短的扫描范围换速度，不虚构来源和精度，不扩预算、不堆新服务。以后可迁移服务器、可隔离增加候选人，目前仅启用 Frank。
- **全中文，内容有用才显示。** 常规界面和叙事正文展示中文。代币名、原币单位、账号、地址和来源名称保留原标识。外文原件、技术状态和内部标识按需查看。
