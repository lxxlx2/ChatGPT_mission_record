# BSC Meme 地址分析模型 V1 — 冻结需求、范围与验收合同（2026-10-13）

**Status: FROZEN_REQUIREMENTS / RESEARCH_ONLY / NO_GO**  
**Scope:** BNB Chain meme; 多钱包跨重大行情识别、重复盈利验证、可复制性，而非历史大赢家排行榜或自动交易。  
**Authority:** `MISSION_SPEC.md`、`docs/REPOSITORY_STRUCTURE.md`、`research/README_BSC_MEME_TOP_TRADERS.md`、相关原始链上证据。  
**Change control:** 本文冻结 V1 用户目标；需要改变样本、成功阈值、计分、时间窗口时须提交单独的版本化变更和独立 Review；历史证据原样保留。**不允许在看到盈利结果后改阈值。**

## 0. 初始用户需求（高于模型指标）

**我们要找的是：在 BSC/Binance 相关 Meme 的“较大、可识别机会”中，过去不止一次真正主动参与且盈利，最好在 2026 年近期仍真实交易、能作为未来手动投资研究参考的公开地址。**

- 研究**每一个主要大机会**，尤其 **2026 年**，包括此前明确提出的「4、龙虾、我踏马来了、MARSCOIN、牛来、Broccoli、TST、MUBARAK、GIGGLE、HAJIMI」等已确认 exact CA。用户指出其余币种可辅助观察钱包是否持续活跃，但**不能拿杂币刷“活跃度/胜率”**。
- 钱包可**不频繁交易**：只要跨多个重大机会稳定抓住，就有价值。长期不再主动交易的钱包要降级。**近期活动 = 原交易发起人、真实 Meme swap**，不是普通 BNB 转账/代币空投/余额变动。
- 目标是**发现多个可研究的钱包并进行公平横向比较**，而不是无限审计 8E6B 或先验认定某钱包最优秀。现有 **23 EOA ×19 exact CA** 仅是已冻结的候选研究集，非全 BSC/全 Binance 盈利地址全集，也非盈利榜前 100。
- 要分析**实际盈利、亏损、资本规模、盈利集中程度、胜负币种、进出场时间、资金来源及地址关联**，把未完成、未买、转账、交易失败、未实现持仓明确分开。不许把未参与的代币全算错过机会。
- 必须回答**是否可复制**：钱包买入信息第三方何时能看到？从该时刻开始延迟 1 /5 /15 分钟，有没有可达的池和正常规模流动性、Gas、代币税及实际可执行卖出？提前交易、狭窄窗口、LP 撤走、内幕/共享控制等不批准为可跟单 Alpha。
- **任何数据不足即 UNRESOLVED，不编造 PnL、市场价格、活跃性、机会分母或盈利榜**；链上优先、官方优先、不引用中文网站作为确认；原始 tx/hash/区块/CA/报价币种/时间戳 Git 证据可追溯。
- **免费路径优先**：复用 Git 原始资料 + 已连的只读 Alchemy BNB 主网；不使用需资金存入/付费的 GMGN API，不向用户索取重复数据，不要求用户逐个下载补丁。
- 不触及私钥、自动交易、告警或生产。研究模型完成后仍需另一 AI **独立 Review → 测试 → 只读本地验收 → 有问题修复**。未过验收则 **PRODUCTION_TRADING = NO_GO**。

## 1. 样本/事件不可混淆的四个集合

| 集合 | 内容 | 分母/作用 | 禁止的推论 |
| --- | --- | --- | --- |
| U: 市场重大机会 | 事先定义、按年份/上市/行情事件冻结的 BSC major meme exact CA + 可执行起点 | **潜在机会分母**，必须验证当时确有可进入市场 | 19 CA != 全市场；创建/第一笔 Transfer != 首次可交易；未买 != 错过盈利 |
| W: 研究钱包 | 当前冻结的 23 EOA + 另行版本化发现集 | 研究样本；先全量横比再重点审计 | 筛选后的赢家 != 盈利排行榜；候选之外的地址不能静默加入 |
| P: 钱包交易回合 | 同一 EOA、exact CA、本人签名/结算、0→持仓→0 或明确开放仓 | **盈利/亏损统计**，必须保留所有观察到的负向与开放仓 | ERC20 transfer == buy/sell；区块 BNB 差 == 因果净利润 |
| F: 跟单执行 | 信号可见时刻、历史合约路径、滑点/税费、实际延迟、资金容量、退出 | **独立的跟单可行性**，只评价可观测操作 | 钱包过去赚钱 != 观察者将来能赚；历史池 spot != 实际成交 |

## 2. V1 明确定义、数据字段和不允许猜的标志

每个 `wallet×CA` 组合**必须包含**：
`wallet, token, ca, transfer_state, observed_transfer, complete_in/out_count, raw_inventory_state, owner_signed_trade_state, recent_true_meme_swap_state, true_swap_last_utc, economic_state, realized_cashflow_by_quote, realized_profit_state, major_opportunity_eligible_state, action_timing_state, provenance_refs, missing_evidence`。

强制分类：
- `CONFIRMED`: 原始交易回执/完整 ERC20 双向日志/原生余额+报价币种，字段在所声明范围直接可核；
- `INFERRED`: 多事实支持但缺内部路径、完整现金流或真实执行；
- `UNRESOLVED`: 证据不足，不能用 0 或 LOSS/NO_TRADE 代替；
- `SPECULATIVE`: 情景测算，严格独立，不进入真实收益排行榜。

状态的精确含义：
- `ERC20_PRESENT` / `ERC20_ABSENT_IN_FROZEN_CA` 仅指**固定 CA 的双向 ERC20 转账存在与否**；
- `SIGNED_BUY_CONFIRMED`、`SIGNED_SELL_CONFIRMED`、`PASSIVE_TRANSFER`、`MIXED_OR_UNKNOWN` 由原始 signer/receipt/quote 分类；
- `PROVEN_CLOSED_NATIVE_QUOTE` 要有数量闭合 + 原始签名、报价进出、Gas 可按 wei 校验，且标记任何未追踪内部流；
- `MIXED_QUOTE_POSITIVE_DIRECTION` 可在 BNB、USDT 各自现金流均正时成立；一正一负需事先选定的历史报价来源及其不确定性；
- `NATIVE_BLOCK_DELTA_ONLY` 属于钱包范围余额事实，**绝不是**完整可归因真实 PnL；
- `RECENT_SIGNED_SWAP` 需要有区块 UTC、from 原签名、实际买卖路径；**2026-10-13 起过去 30 天 = [2026-09-13, 2026-10-13] UTC，边界冻结**，晚于截止的真实核查另记有效期；
- `ACTIVE_MAJOR_PROFIT_CANDIDATE` 仅作为研究资格：至少 **2 个不同重大 exact CA 的实际正向闭合回合**，保留同钱包全部已观察负向，存在至少一个 2026 年主动成交，最近 30 天活跃单列三态（确认/确认不活跃/未知）。这**不是**自动交易信号或全市场统计获胜率。

## 3. 比较指标——先分层，不造加权总分

模型 V1 不在数据没全时发明 100 分“高手指数”。优先形成可以对比的几层指标：
1. **参与覆盖**：19 CA 转账证据覆盖、按 2025/2026 年重大币分组，带完整度；
2. **签名行动与时间**：真实本人买卖覆盖率、重大机会最早可观测入场、最近 30 天真实 swap，区分普通原生转账；
3. **经济表现**：完成且可归因的各币/回合收入和亏损；原生钱包区块变化单列，不与 WBNB/USDT 强行相加；把最大一笔盈利剔除后的符号和净收益、亏损回合按相同单位比较；
4. **资金/地址关系**：初始资金、共享上游、双向转账、可能多钱包/路由商控制的证据等级，不把同资金源自动判断为同人；
5. **漏买资格**：只有 `wallet在真实可交易信号时具备可买资金/路由 + 当时有公开可观测路径 + 该时刻策略触发 + 可实现获利退出` 才能计入 qualified miss；未满足则 `UNKNOWN`；
6. **跟单可行性**：真实信号先于成交、延迟 1/5/15 分钟，不挑事后有利时点，不允许把无资金深度的池当成交；费用/退出与失败保留。

所有当前无法比较的利润保留 `UNRESOLVED`；**不按未知利润排序**。允许按“下一步证据投入优先级”排序，但须标注 `RESEARCH_PRIORITY_ONLY`，不得传播为收益排名。

## 4. 接受/拒绝门禁（冻结）

- **G0 规范与范围冻结**：本文 + 阶段计划进 Git、单独研究分支与 Draft PR，用户变更需显式版本化；
- **G1 证据底座**：沿用 V21 `23×19=437`，148/148 正值转账数量闭合，289 无正值；所有来源 SHA、样本偏差、2026 年覆盖比例写入 manifest；
- **G2 广度优先横向比较**：**23/23** 钱包同列有参与、缺失、主动交易、最近签名、损益证据状态；不得只展示 8E6B；
- **G3 已证明的重复盈利候选**：至少两币正收益原始链证据，各失败币同期保存，报告最大赢家贡献；未知币不计赢也不计输；
- **G4 近期 2026 / 大机会与 missed-denominator**：2026 年明确机会范围和上市/可执行场所，样本外同口径检查；未观测不能冒充确认未参与；
- **G5 真正跟单回测**：先冻结时间/资金大小/费用/路由/信号可见性，再用 untouched 2026 期间进行 1/5/15 分钟跟踪；不能假定事后池价、退出和投资者视角；
- **G6 Review / 测试 / 只读本地部署**：独立其他 AI 审查后修复再考虑可视化/运行时。**绝无自动实盘交易授权**。

不在 G1/G2 成立之前做 G5 参数调优；不为边界案例无限延长一个钱包分析而推迟横向 23 钱包比较。

## 5. 不在 V1 范围

- 未经证明的全 BSC 历史前 100 真实盈利榜、所有 Binance Alpha/TGE 全币宇宙；
- 从过时余额“补”交易报价；未经许可的交易、自动监控、邮件/本地提醒、私钥/授权；
- 对未买或冷钱包推断“错过 10×”、对转账接收者推断“高胜率”；
- GMGN 付费/要求下载散落脚本；
- 以漂亮历史案例替代真正的样本外验证，或以需求扩张替代模型上线门禁。
