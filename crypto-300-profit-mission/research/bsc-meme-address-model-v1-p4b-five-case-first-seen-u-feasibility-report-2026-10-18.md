## 二、真正缺少、无法从旧区块时间代替的事实

这五笔本人首买过去确曾签名上链，**但现有 Git 归档未记录任何独立公网观察者实际首次收到原始 signed transaction 或有效信号的本地接收 UTC**。`block.timestamp`、买家事后成功成交、DEX 历史创建/首个 Transfer 和其他人的增仓，均不是该独立公网观察者的真实到达时间。对已过去的历史样本不能凭想象补该时间。

因此五条的 `first_public_observer_received_utc=null`；对应 +60/+300/+900 秒三个买入时点的**真实可支付本金、实际池交易路由、深度、Gas、税费、收到的 token、有效退出路径、实际回款、观察者净利润均没有达成证据合同**。五条保持 `P5=BLOCKED`，不能算 5 个模拟负样本，也不能直接判断是否错过 alpha。冻结样本用于展示哪些判断能验、哪些不能验。

## 三、下一步可执行的功能里程碑（不能跳门禁）

1. 先把未来 read-only 第一观察时刻采集合同版本化：观察者所在机器及独立公网 RPC 节点、收到时本地 UTC 与单调时间/时钟校准证据、原交易哈希、钱包/CA/池、签名来源、接收时区块/链 ID，原始未改写存档及 SHA。历史区块时间单独存为 `consensus_time`。**没有历史 archival public first-seen 时，不可把这五条用作 P5 收益训练标签**。
2. 入场资金量、报价币种资金来源、入场交易地点与可接受费用、+60/+300/+900 秒必须在收益结果之前固定。当前 `capital_amount` 与 `exit_policy` 特意保持 UNKNOWN，下一正式可成交实验必须先按既有 G4/G5 合同明确，禁止事后挑最好的退出点。
3. 相同规则并行包含真实负向、过期、未成交、无退出/未知状态。没有执行日志就保持 `BLOCKED`，不得将别人成功卖出当作自己成功成交。
4. 本轮没有 RPC 查询，没有监控程序在 Mac 后台运行。未来在用户另行授权 Mac 只读实测、外部 Review 和完整测试之前，不部署、不断言真实 P5、更不交易。

**结论：** 五样本已预冻结，跨四市场的历史证据分级可审计；**首次公开观察 U 仍 UNRESOLVED**。阶段门禁继续 `P4-B=PARTIAL / P4-C=PARTIAL / PUBLIC_EXECUTABLE_U=UNRESOLVED / P5=BLOCKED / PRODUCTION=NO_GO / NO_MERGE / NO_DEPLOY / NO_GMAIL / NO_TRADE`。
