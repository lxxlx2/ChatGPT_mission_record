# Mission Run Audits

Automatic audit filenames are intentionally machine-stable.

Current convention:
- `HHMMSS-start.md`
- `HHMMSS-final.md`

Older pure-time `HHMMSS.md` files remain immutable historical records and are not bulk-renamed.

Human/manual records may use semantic suffixes such as:
- `HHMMSS-architecture-refresh.md`
- `HHMMSS-automation-repair.md`

Do not rename historical automatic audits purely for readability. Use indexes or semantic manual records instead.
