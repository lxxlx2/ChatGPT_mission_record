## 预定义比较口径，不允许中途按收益调参

- **Arm W** 全269条原始WATCH（含未来有无SETUP，不根据后验过滤），**Arm S** 全120条原始SETUP。两条arm均以每个信号真实`observed_ms+3分钟`的1m OPEN代理入场、入场后固定24h的1m OPEN代理退出；每边假定手续费10bps，滑点20bps与压力100bps，不假装历史真实L2 ask/bid。每个事件的来源状态、获利/亏损及完整身份可追。
- 主量表A：所有事件的**不考虑同币资金锁定的独立价格代理**，原始269/120完整分母；同币短时重复、来源删失均逐项列示，不能暗示269/120次全能成交。
- 主量表B：两条arm都按照各自原事件`observed_ms,event_id`固定顺序，对同币使用**因果式24h占用**：入场+3m分钟存在，价格>0、入场成交笔数>0、入场1m quote>=30 USDT则锁仓直至该入场时间+24h。即使未来退出来源缺失，**也不得用当时不知道的未来退出结果释放已入场仓位**。未达到入场质量的事件应标源拒绝不锁仓；所有拒绝、重叠保留完整原事件分母。资金仅对同币占用，不假装已施加全市场300U总资金限额。其余退出源质量按照已冻结上一轮：退出一分钟必须有成交且quote>=30，退出前最近5分钟不得零成交；若缺失保留CENSORED。
- 辅量表C：只对原原始队列有**唯一按同一币+15m queue窗口归属**的SETUP，找到关联WATCH的`observed_ms`，再核实队列`first_seen_ms`与原WATCH事件时钟完全相等；有多个同时生效队列的SETUP标`AMBIGUOUS`、无对应标`UNMATCHED`，绝不凭盈利选哪一个。对可唯一匹配且两个arm入场分钟都有效的条目报告**WATCH+3m 与 SETUP+3m入场价格相对变化**，以相同24h持有结果双边均有源时做逐对净收益差；对只一边可评价不抹掉。***只做事后等待代价解释，不允许把“后来确认SETUP的WATCH”作为能在WATCH时预知的下单规则***。
- 最终必须报告每组合法/重复/源拒绝数、24h价代理胜率、中位、均值、tail、历史假定30U互不约束PnL以及有对应WATCH的SETUP计数。分组的 WATCH(269) vs SETUP(120)存在选择机制与时点差异，**只允许描述性差异**，不允许因前组胜率较高就推因果`D1 improves/harms PnL`或下BUY。
- 所有初始入场时间严格在信号之后，不用信号分钟开盘；同币资金占用源层级不得看未来；独立配对不能把已知未来SETUP用作实时买币筛选。真实可执行净收益、历史point-in-time盘口、费率级别和订单成交仍为`UNVERIFIED`。
