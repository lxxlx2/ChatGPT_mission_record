# ADR-006 — Monster 恢复首次可交易高倍数投资价值主线与研发资源止损

- 决策日期：2026-10-28（Asia/Bangkok）。
- 状态：**USER_APPROVED / EFFECTIVE_FOR_FUTURE_R_AND_D**。用户在审阅旧路线与新路线偏移后明确回复“同意”，批准以下主线、预算和工程治理修正。
- 范围：`crypto-300-profit-mission/monster/` 和该模块在 `local-agent/` 下的新增研发；仅 PR #30、`research/monster-v4-local-discovery-20261010`。此决议本身不授权 Git 合并、部署、网络定时采集、自动交易、发邮件或付款。
- **supersedes: ADR-004 的“CEX Spot/USD-M D0→D1→D2 为唯一/第一产品盈利主线”及其优先级/下一开发选择器**。保留 ADR-004 的历史事实、真实测试、已冻结业务安全门禁、Frank 隔离和已存在文件；不改写旧 ADR 原文。
- **constrains: ADR-005**：保留其预注册规则和三窗口作为独立冻结的历史研究提案，但从当前投资研发主线降级为`FROZEN_COMPARATOR_RESEARCH_ONLY / NO_FURTHER_VARIANT_DEVELOPMENT`。不是宣布 ADR-005 在未来样本上的收益已经验证，也不是对其冻结旧实验重写样本。
- 保留：2026-10-19 `MONSTER_EARLY_ARCHITECTURE_CONTRACT_V1`、ADR-001 的 D1/D2/D3、原先已冻结的 Base/BSC 30 例与各停止门槛、Stage77 安全验收边界。若发生冲突，以本 ADR 新批准的研发**方向及资源分配**为准，不据此擅改任何旧样本标签或阈值。

## 1. 唯一首要投资问题：高倍机会是否能提前识别且真实退出

主要研究对象为代币**第一次实际满足公众当时可观测的双向可交易准入**，包含后续 5×/10×、普通波动、死亡、流动性撤回、迁池、未上市、数据缺失的全样本，不按事后赢家筛人。BSC 是现有源验证试点，**不是**整个平台范围；有独立完整来源时才考虑其他 EVM/Solana/Launchpad/Alpha/CEX 首上市场所。不得声称尚未覆盖的场所已覆盖。

必须逐级回答三个独立可证伪问题：

1. **来源 / 当时可知**：是否能从完整、包含死币及普通币的连续原始事件重新建立同一母体？`chain_event_at`、真实历史公众`available_at`及事后`ingested_at`严格分离；不支持则`NOT_SCORABLE`，不得凭今日日志或事后榜单冒充现场已知。
2. **识别能力**：在第一次真实合格时点，用当时可见因素发现后续 30/90 天真实可卖出 5×/10×，同窗口同准入母体对照随机/单一流动性基线；原 CEX 动量 WATCH/D1 只作**可比范围内冻结的对照**。
3. **经济兑现**：研究金额、买入可执行价、退出实际可得金额、延迟、手续费/滑点/税/Gas、资金并发占用、归零/失败退出及净收益；没有合格证据不推断`BUY`或可成交盈利。原 15 个彼此足够独立、90 天标签成熟、固定研究名义额可卖出 10× 是探索最低功效计数，不是盈利通过标准。

**研发进度只能按改善这三项的可靠新证据判断**，不是按 commit、测试、PR、workflow 或 Review 数量判断。

## 2. 旧 CEX 动量盈利假设停止追加开发，保留可复用资产

10 月 19 日决策中，旧 CEX 盈利假设已属 `PROFITABLE_BUY_THESIS_NOT_SUPPORTED / NO_GO`。Spot511、Stage30/162/518 等历史证据有多项负面或证据不足，但相互样本、规则和假设可能重叠，**不得未经检验称为四个统计独立反例**。CEX 交易入口、官方发行方原始档案、身份/时间核验、SQLite/D0 原封存日志、D2 可交易性核验可继续作为**只读来源/交叉市场生命周期和对照基线**；不能重新定为盈利策略主线。

- ADR-005 的 `D1_RBTC15_LAST5_V1` 仍是`RESEARCH_CANDIDATE_NOT_VALIDATED`，不依据已经曝光的 46 SETUP 或分钟表现继续调参，不再为三个未来窗口开发新变体、逐 P1/P2 反复补工作流/报告，不将工程完整性当成收益假设已获支持。
- ADR-005 三个事前冻结的窗口（2026-11-02 / 11-16 / 12-01 00:00 UTC）不回填、不换日期、不自动采样；**只有存在独立明确的一次性采集授权时**，才允许按此前固定规则归档当时原始资料。该归档不能自动触发新盈利研究或恢复旧模型方向。
- 已明确授权的 **2026-10-28 06:00 UTC USD-M Stage97 单次 T0 只读采集**是另一预先冻结的计划，**仍保留该特定范围的授权**。请求文件 `monster/evidence/monster_stage97_one_shot_capture_request.json` 当前为 `authorized_one_shot=false`，需用户在 05:45–06:00 UTC 的合法窗口**主动触发**；不会设 schedule、不会代用户提前开启、更不能把之后抓取伪装为该时点。归档不构成恢复旧 CEX 盈利开发授权。到时未触发则`T0_MISSING`，不得自动补采。

## 3. BSC P0 来源零预算及 2026-11-02 硬停止

- Plan A：先前公用 RPC/免费 `eth_getLogs` 的实际历史来源尝试不足以证明连续完整可读；未证明不能写`PASS`。
- Plan B：实测 AWS 2025-07-01 BNB `blocks` 与 `transactions` 两文件只有块、普通交易、calldata 等列，未见可直接恢复的原生 Logs/Topics、LogIndex、完整 receipt/status；为`AUXILIARY_ONLY`。不把这误宣称成全 AWS/BSC 产品均无日志；但**禁止继续在同两份 Footer、22 SELL、7 roundtrip 上扩大无增益探针**。
- Plan C：**总支出上限仍为 $0，明确不授权付费/充值/订阅/购买数据**。若未来真实供应商提供可核验的历史日志、回执、完整覆盖、导出许可、实际完整报价，可以先只读提交决策，另取用户明确授权；不存在默认可用的“几十至两百美元”供应商报价。
- 2026-11-02 来源截止、30 原身份、24/30 PIT、18/30 固定条件双向可卖及原两次手动 CI 预算不变。当前已知 P0 为 `INSUFFICIENT_COVERAGE`，历史 `available_at` 30/30 UNKNOWN，固定金额双向可兑现性 `NOT_SCORABLE`。如截止仍无真正合格源，则**正式停止 BSC 此历史来源路线，结论 `SOURCE_BLOCKED / REJECT_INSUFFICIENT_PIT_COVERAGE`，P1 禁止启动**；不将失败扩大为“全部早期链上投资不可行”或全 Monster 失败。
- 不得在 11 月 2 日前为了避免失败而改分母、重选时间窗、补伪 PIT、以新模型绕过 P0；截止没有自动定时执行，后续按实际证据结案。

## 4. 研发膨胀止损，优先复用现有文件而不是增加新工程

- **即刻冻结净新增** Monster 专属 Stage/ADR005 分支脚本、GitHub workflow、Review 轮次文档。当前用户仓库审计报告为约206个 Monster workflow、257个 `monster_v4_*` 脚本、23个独立Review文档，这些仅作**用户报告基线**，本 ADR 不声称独立重新点数验证。
- 旧文件与审计记录`ARCHIVE_IN_PLACE`，**不得为凑上限而删除有效历史证据**。新的必需能力原则上改现有 `mission_agent/early/` 和统一入口，配合原测试及**现有** CI；只有实际解除关键 P0/P1 因果/源正确性阻断、明确证明无法复用且经用户新增授权时，才允许提出容量置换/新增方案。
- 每 Phase 原则上**一次针对冻结 SHA、真实源和收益风险的独立外部审核**。重要 P0/P1/PIT/资金计算缺陷发现后，必须在同一审计范围内做定向修复与复核，不可以“减少 Review 数量”为由放行严重问题；普通低风险文档/边界修补不继续组成无穷审核循环。
- 保持 P0 每 Phase 最多一份主 JSON 与一份主报告，必要修订覆盖原文件，不新建 Stage 名称代替 ADR 约束；未有新真实来源、具体阻断或可核证的投资收益增益则**不新建代码/文档**。
- 任何将 CEX 旧盈利模型重新升级为主线、开放 Plan C、修改研究标签/名义额/停止条件、添加 cron/launchd/定时工作流、发送 Gmail/交易的请求，均需以后**新的明确用户授权**。

## 5. 当前状态与下一个有效决策

- 全 Monster：`G6 NO_GO / NO_MERGE / NO_DEPLOY / NO_MONSTER_GMAIL / NO_TRADE / NO_NEW_AUTOMATIONS`；Frank 及已有生产任务一律不动。
- BSC 历史 P0：`INSUFFICIENT_COVERAGE / P1 BLOCKED / PIT NOT_SCORABLE / G4 UNKNOWN`，仅在出现**新的合格原始来源事实**时允许有限 P0 只读复核，否则于 2026-11-02 依据冻结证据结项。
- CEX 旧动量：`FROZEN_BASELINE_ONLY / PROFITABLE_BUY_THESIS_NOT_SUPPORTED`。现有审计/工程资料不自动提升投资门禁。
- **下一项值得投入资源的任务**只能是清楚显示对原链上首次交易生命周期的完整且合法来源、真实 PIT、可卖出条件有什么新增覆盖；若无新增证据，记录停止并暂停研究，而不是继续补报告或测试数量。

此新 ADR 是一次针对**此前方向偏移的用户批准决策**，不会直接修改以往历史统计/源 SHA/代码阈值，也不代表代码或盈利模型已经通过独立审查。
