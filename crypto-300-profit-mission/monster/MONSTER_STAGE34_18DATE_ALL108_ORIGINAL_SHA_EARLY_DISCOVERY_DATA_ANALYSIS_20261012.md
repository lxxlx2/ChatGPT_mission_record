## 三、关键发现：首次WATCH很早，真正靠近启动的信号仍需分离

对84个真正提前的2×币日期分别分析两种时间，禁止混为一个指标：

| 时间定义 | 84个严格提前的2×事件 |
|---|---:|
| 第一次WATCH距首次2×的中位提前量 | **1,055分钟（17小时35分）** |
| 首次2×前**最近**一条WATCH的中位提前量 | **151.5分钟（2小时31分30秒）** |
| 最近WATCH提前至少5分钟 | 78/84 |
| 最近WATCH提前至少15分钟 | 76/84 |
| 最近WATCH提前至少60分钟 | 61/84 |
| 首次WATCH比首次2×提前超过24小时 | 30/84 |
| 首次WATCH比首次2×提前超过72小时 | 13/84 |

这不是宣称能在第一次WATCH时赚钱：大量真正大涨标的在第一次WATCH后经过十几小时甚至数天才触及2×；后续重复的WATCH/强度更新可能更贴近启动。**数据支持区分「早期纳入观察」与「临近爆发行情重新增强」，但不能事后把最近的一条WATCH当成真实当时已知的最佳买点。** 策略设计需要按当时能够观察的证据追踪状态转变，不能调用未来首次2×时间。

## 四、普通币对照：发现率高≠选币准确率高

在全部7,776个来源完整的币日期中：

* **1,227**个币日期至少触发一次WATCH；**2,391**次WATCH是多个事件/重复报警，不应与币日期分母混淆。
* 其中**86个**币日期随后在冻结七日窗口内触及2×且曾WATCH：84严格提前、2迟到。另**2个**最终2×却从未WATCH。
* **1,141 / 1,227 = 92.99%** 已WATCH的币日期，七日最高价没有触及冻结基准的2×。它们属于`NON_2X_WITH_WATCH`，**不应全部定义为错误通知**：一些可能出现了有价值但不到翻倍的上涨，或者首次WATCH时已远离基准价。这一标签不是费后盈亏或真实买入建议。
* 其他 **6,547** 个完整币日期既无WATCH又无未来2×，它们是必要的普通行情基线，不得丢失。

不同窗口差异显著：2026-02-04这一整周，445个完整币日期、160个有WATCH，只有2个币日期未来达到2×，其余158个有WATCH者不达2×；2025-04-19窗口394个完整币日期、88个有WATCH、12个未来2×；2026-08-04窗口478个完整、63个有WATCH、9个未来2×。风险在于市场环境、热度和BTC同步波动均可能影响预警负载，但本轮未做BTC对照回归，不据此发明过滤器。

特别值得注意的集群：在 **2026-02-06 00:36 UTC** 一次三分钟原轮询中，**96个不同币日期的首次WATCH恰好同时发生**，其中仅1个在本轮固定基准下未来达到2×。此前Stage26对该UTC小时所有重复WATCH记到104条（包含96个首次和其它后续WATCH），**二者口径不同不可相互抵触**。这是优先要解释的市场共振/通知压力现象，不能因而直接套用Stage29此前已失败的「爆发群体统一BUY」方案。

这批统计最有效的产品分工是：**D0/WATCH负责高召回与持续观察；风险/重点排序和状态更新负责减少用户注意力浪费；IGNITION必须另有当时可见的强证据与成交条件，WATCH不直接等于可以买。**
