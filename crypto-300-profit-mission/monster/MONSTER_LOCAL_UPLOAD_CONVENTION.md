# Monster / Mission 本地上传文件的命令约定

更新日期：2026-10-10
来源：用户在本对话中明确提出的长期操作偏好；适用于后续所有需要用户在 Mac 生成并上传文件的步骤。此 Git 文档是一条项目级持久约定，并不声称已经控制 ChatGPT 账户的 Memory。

**规则：只要需要用户上传 Mac 本地文件，终端命令必须在成功生成并验证文件后，自动让 Finder 打开所在目录并选中目标文件。**

推荐的 zsh / Bash 结尾：

```bash
FILE="$HOME/Documents/ChatGPT/monster-backtest-packet-20261010.zip"
test -s "$FILE" && open -R "$FILE"
```

- 输出为单个文件时，使用 `open -R "$FILE"`，不是只输出路径，也不是 `open "$FILE"`（后者会打开文件而非在 Finder 中选中）。
- 如果输出多个文件，优先先打包成一个可上传 ZIP，再 `open -R "$ZIP"`。如果必须上传多个文件，对每个需上传的文件说明并提供对应 Finder 选中命令。
- 所有交给用户执行的命令应尽量是**完整的一次性 Mac 命令**；按用户要求**不要包含 `#` 注释行**。
- 检查输出文件存在且非空后才 Finder 选中。若生成失败，清楚输出错误而非仍打开上一轮旧文件。
- 脚本/导出器尽量优先读取已有本地数据，不修改 Frank、现有监控、正式数据库或任何持久服务；允许必要的用户可见输出文件。
- 这条交付约定独立于研究模型的参数、交易授权和上线规则；并非允许改写生产策略、开自动交易或新增任务。
