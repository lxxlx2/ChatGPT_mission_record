### 本次证据如何改变业务决策

**ACC 是较早的观察候选，不是已经证实的 alpha。** MULT 晚到可能削弱跟随机会，但它在归档时仍有正持仓，不能仅凭时钟武断地断言“所有 MULT 无可跟空间”；真正阻断 **INVEST/TRADE** 的仍是 **0 条按实际可见时间、用户金额、交易路径和费用匹配的可执行往返报价**。对 P1 截止时的**预先候选管理决定继续维持 `INVEST_NO_GO`**（如无新的独立有效证据），实盘 `TRADE_NO_GO` 立即成立。没有因本节追加预算、增加新门禁或申请一次性新 API 请求。

**可复算方法：** 对 M3 32 signal 分成 22 ACC /10 MULT，按 `episode_id` 唯一匹配；用整数 `triggered_at - position.first_buy_at`、`MULT.triggered_at - ACC.triggered_at` 排序计算中位数；用 `sell_count>0` 和 `BigInt(current_token_position)>0` 计数。六币 lot 的 `signal_trigger_bkk`、`exit_last_bkk` 均以 `+07:00` 转 UTC，与 ACC 的绝对秒时间验证一一相等后求时差；全程不使用 minted symbol 名称代替 exact mint/episode 身份。
