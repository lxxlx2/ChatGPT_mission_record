# MONSTER_D1_V3_SPEC — frozen two-stage architecture

GT V1/V2, existing raw archives, metadata identity mapping, event windows and future-only labels are unchanged. This design uses only already exposed TRAIN summaries and causal TRAIN features; 2024 outcomes are locked. V2-237 is a comparison diagnostic, never a winner. No D2/D3 or live Monster runtime.

Stage 0: valid closed hourly candle, current quote >=10000 USDT, known close. Stage 1: unchanged broad V2-001 independent A/B/C/D/E OR pathways with parameters [0.90,2,3,0.80,0.90]. Stage 1.5: persistent broad trigger for 2 or 3 consecutive complete bars, close retained at >=75% of the close at the beginning of that consecutive streak, current r1 <=0.5 or1.0, current r4<1.0. These are causal local overextension proxies, not GT 2X crossing features. Missing bars reset streak and lifecycle, including recovery context.

Independent confirmation families:

- QUALITY: mean quote of last persistence window >=50000/100000/250000; current quote >=half that limit; mean trade count >=20; mean V2 volume acceleration >=1.2. If a full prior168h quote series exists, current quote midrank versus strictly previous168 bars >=0.80; for verified young instruments (<168h) unavailable long history is explicitly allowed. Young instruments use half the configured quote minimum. Unknown age receives no young exemption. Quote/trades are activity/liquidity proxies only, no fabricated order-book history.
- RS: current BTC-relative4h >0.01 and relative24h >0.02, AND token4h minus same-time same-venue broad-alt median4h >0.01 (at least20 complete peers), AND BTC-relative4h positive for the entire persistence streak window. Missing BTC/market inputs fail RS only. Broad-alt median includes available same-venue instruments; this is an instrument-weighted market proxy, not a sector index.
- DUAL: verified identical entity only; simultaneous counterpart venue has positive4h return, quote>=10000 and positive1h return; source instrument also positive1/4h. A future listing cannot confirm an earlier candle. Ambiguous instruments never merge. For conditional_dual=true, an existing contemporaneously eligible counterpart requires DUAL; an absent counterpart is unavailable/exempt, so Spot-only new listings are not automatically excluded. conditional_dual=false only supplies DUAL as optional confirmation.

Three confirmation policies: QUALITY_OR_RS; QUALITY; QUALITY_AND_RS_OR_DUAL = QUALITY AND (RS OR DUAL). Persistence is always mandatory, plus selected independent confirmation. Primary path is first currently passing A/B/C/D/E in fixed order; remaining current paths are supporting_paths. Candidate retains all families PASS/FAIL/UNAVAILABLE, conditional-dual applicability, age classification and causal measurements. Broad triggers that fail confirmation do not emit candidates.

Lifecycle: one candidate on confirmed inactive->active per instrument/config, rearm after3 consecutive failed confirmation bars. A gap resets unknown/recovery; recovered observations remain audit evidence, not an uninterrupted earlier trigger. Changed supporting paths during active state are recorded in attribution counters without a second complete candidate. No retrospective daily topK, quotas or labels in features.

Finite grid is exactly 2 persistence x3 quote x3 policy x2 overextension x2 conditional-venue=72, enumerated in JSON field order. No trigger-threshold grid expansion. Config source and evaluator implementation are committed before full TRAIN grid. Frozen file hashes and ancestor commit are checked each run; changing frozen inputs requires a new reviewed version.

TRAIN=2021–2023 with 2020Q4 warmup. VALIDATION=2024; 2025–2026 exposed diagnostics only. Reuse V2 frozen feature preprocessing and saved metadata; supplemental candle shape/trade/quote-percentile features process one instrument and one weekly slice at a time. Supplemental history may be preprocessed causally, but never compute 2024 GT until an eligible TRAIN winner is committed.

Calendar counts include zero-candidate days; gate median unique entities/day<=100 AND nearest-rank p95<=150, instrument counts also retained. Event/unique-entity recalls >=5/10/20X use frozen earliest candidate [anchor-24h,peak] and <=2X prehit, strict<2X separately. Instrument and entity event identities preserved. All leads have explicit sample denominator and include late triggers; no trading return claim.

Winner selection: discard configs failing either ceiling. Among eligible, lexicographic descending >=5X entity prehit recall, >=5X strict-before2X recall, >=10X entity prehit recall, median >=5X lead-to2X (missing worst); then ascending entity median,p95; then descending minimum per-TRAIN-year >=5X recall (years with no events excluded), then config ID. This order is frozen, never manual. All yearly volumes and recalls are reported. N=7/2 high tiers are descriptive. No eligible winner => MONSTER_D1_V3_NEEDS_REDESIGN; stop, no validation/V4.

Winner result must be committed before one immutable 2024 evaluation of that winner alone. Validation keeps V2 gates: >=5X N>=20 and recall>=90%, ceiling100/150; >=10X require N>=10 for quantitative proof and recall>=90%, strict-before2>=70%; >=20X N>=5 then90%, otherwise descriptive. Insufficient5X => INSUFFICIENT_DATA, not validation PASS. If10X insufficient but adequate5X passes, status MONSTER_D1_V3_VALIDATION_PASS with explicit 10X_NOT_VALIDATED. No 2024-guided tuning or second winner.

MMT/AVNT/BTW are explanatory regressions after freezing, never design inputs; compare V2-001 reference trigger times with V3 selected winner (or deterministic lowest-noise diagnostic if no winner). Pareto frontier uses entity median,p95 versus5X prehit and strict-before2X recall; every above-ceiling point remains ineligible. Noise attribution includes broad path activations rejected by confirmation and candle-wick/activity distributions; GT extreme-range/low-anchor flags stay untouched. False-positive load uses complete candidate forward168h max<2 only as offline audit; censored outcomes excluded explicitly.

Single low-priority worker; peakRSS<1GiB; abort if Meme stale>90s, gap/duplicate rises or429 count rises. Read Meme health/SQLite only; no Meme source/state/agent mutations. No task/Gmail/wallet/trade/NFT/Core Price/portfolio changes. Stop for review after delivery.
