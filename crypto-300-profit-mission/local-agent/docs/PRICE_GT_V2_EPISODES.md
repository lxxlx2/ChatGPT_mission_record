# PRICE_GT_V2_EPISODES frozen contract

Uses unchanged Decimal34 PRICE_FEATURE_V1 causal features plus signed reversal components from the same15 bars: drawdown=(local_high-close)/local_high, drawup=(close-local_low)/local_low. Reversal direction is UP if drawup>=drawdown, otherwise DOWN. Decimal ties favor UP. All price decisions use Decimal ROUND_HALF_EVEN. Fully warmed contiguous closed canonical bars only; non-BTC BTC features must align exactly. Features missing after a gap do not generate labels; a canonical gap is a data failure for120d gates.

Families: FAST_MOVE abs1h>=4%, direction sign1h; MEDIUM_MOVE abs4h>=7%, direction sign4h; REVERSAL max(drawup,drawdown)>=5%, direction defined above; BREAKOUT >=1.5% beyond each sample's own prior24h high/low for three contiguous samples on same side, direction that side; VOL_EXPANSION vol5>=4*prior24h same-scale median (median>0) AND abs5m>=2.5%, direction sign5m. These are independent fixed labels, not search thresholds. Partial equality of one candidate threshold and a GT threshold does not by itself validate the configuration: episode-direction matching and all load/recall gates across independent families and held-out validation still apply.

At one minute, if material families imply opposite directions, choose the direction of the first active family in priority FAST_MOVE,MEDIUM_MOVE,REVERSAL,BREAKOUT,VOL_EXPANSION. Include only families with that direction in current type set; retain all raw family diagnostics for conflict counts. There is one selected material episode at a time per asset, rather than duplicate UP/DOWN labels from a wide-range bar. This conflict policy is explicit and frozen before search.

First selected material sample starts an episode. Same-direction active samples merge across families; type set is union over episode. Less than30 consecutive fully observed inactive minutes leaves it open. At the30th inactive sample it ends at that confirmation sample; record last_material_time separately. A selected opposite-direction material sample immediately ends the old episode and starts a new opposite episode, regardless of inactivity timer. Unknown/gap is never inactivity credit. Boundary tail is right-censored. Onset begins in warmup -> left-censored/excluded from partition counts, even if still active inside partition.

start_time=first_material_time=first qualifying bar's exclusive close timestamp; never backdate using future data. episode_id=gt2e:<asset>:<onset_ms>:<UP|DOWN>. Fields: episode_type_set,start_time,first_material_time,end_time,last_material_time,peak_magnitude (largest absolute fractional move among direction-selected material return/reversal/breakout/5m price metrics),peak_time,max_drawup_or_drawdown (max absolute excursion of closes relative to onset close),source_window=[first input warmup open,episode end],input_hash (rolling SHA256 of immutable canonical input through episode end),censor status. Peak/end may use later price path; onset cannot. Prior24h references exclude current; reset and causal rules are identical in batch/incremental paths.

Tests require90-minute continuous signal -> one episode; flicker<30min -> same;30inactive minutes -> next signal new;material reversal -> new opposite episode; multiple same-direction families -> one type union; GT builder API rejects candidate/GT-derived input. Realized volatility alone is not directional material without the required price move.
