## What this stage actually adds

`f0_l1_adaptive_source_core.py` implements one orchestration function `collect_adaptive_injected()` and **does not import real HTTP, socket, urllib, SSL, requests, WebSocket, subprocess, or a production CLI**. The caller supplies `post`, `clock`, `mono` and `sleep`. **A caller-provided `post` callback can perform real network I/O**, so this function alone cannot authenticate whether it was authorized, and must NOT be wired to a real HTTP sender before new user consent plus review of the exact concrete runner+permit. All new tests pass in-memory fake callbacks only.

The function performs: exact raw PR116 PRIMARY and documentary Router blob checks *before any sender call*; one journalled `eth_chainId=56` and one initial `eth_blockNumber`; then uses the already developed adaptive scheduler to periodically consume journalled HEAD reads and fetch only heights at or below the most recent **source-reported** HEAD. It enforces one total cap including chain/head/refresh/block attempts and a finite wall-clock deadline via the existing extracted `f0_l1_durable_journal.Journal`, and makes no automatic retry after any result=null/failed block. A HEAD source error, regressed HEAD or 3 consecutive unusable blocks stops. Each supplied raw response is archived privately with journal digest, and any interrupted callback leaves pre-send `ATTEMPTED_OUTCOME_UNKNOWN` without fabricated report.

**New actual technical milestone:** every initial/periodic HEAD read saves source-reported `sampled_head`, local receipt time, last attempted and last successfully received block heights, and `sampled_head_minus_last_attempted_height` and `sampled_head_minus_last_received_height`. These enable verifying **sampled node HEAD-vs-consumer backlog trend**, which was missing from the first real 60-block sample. A fast-growing backlog can show that a single source/consumer was not catching up in the observed window; it is **NOT** an independently verified global network head lag, mempool first-seen timestamp or tradable signal latency. Sample output is explicitly `INJECTED_TRANSPORT_UNVERIFIED` and records `external_real_rpc_calls=UNVERIFIED`, rather than falsely claiming an arbitrary callback made zero real requests.

Block parser reuses frozen PR116 signer and documented Router candidate classification; report contains aggregated counts only, no public wallet/tx hashes, no E2/E3, swap causality, quote or profits. Parent hash comparison can independently verify **N−1 internal links** among adjacent received full blocks, but the first saved block is **never** marked anchored to the initial head; missing intermediate blocks deliberately prevent inventing a parent link.
