# ChatGPT Mission Record

本仓库记录 ChatGPT 三个长期任务的实际执行情况。

目录：

- `airdrop-tge-monitor/`：空投、TGE、投资者分发、Claim 与 Clay Shares 监控
- `us-stock-daily/`：美股每日晨报
- `crypto-daily/`：Crypto 每日情报

## 记录要求

每次任务实际运行都必须创建一条独立记录，包括：

- 任务实际运行时间，Asia/Bangkok 与 UTC
- 本轮是否成功完成检索/生成
- 检查范围或报告窗口
- 是否发现需要通知的事件
- ChatGPT 是否产生用户可见通知
- Gmail 是否尝试发送
- Gmail 是否发送成功
- 邮件主题与 Gmail message id（如有）
- 失败或异常原因（如有）
- 对空投/TGE任务，记录关键官方来源与被跟踪的官方帖内链接

记录采用每次运行一个 Markdown 文件，路径建议：`<task>/runs/YYYY-MM-DD/HHMMSS.md`。

注意：GitHub 运行记录与用户通知相互独立。空投/TGE任务即使本轮没有新事件，也必须写 GitHub 记录，但必须对用户和 Gmail 保持静默。
